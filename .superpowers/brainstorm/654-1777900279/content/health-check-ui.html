What gets checked

  • Embedding model — downloads model if missing, runs a test encode, verifies output dimensions
  • ChromaDB — creates a test collection, writes + reads a record, verifies pysqlite3 patch is active
  • Ollama — pings the API, checks that the configured model is pulled and responding
  • SQLite / disk — verifies the data directory is writable and not in a cloud-sync folder

Behavior

  • Runs automatically on first launch (flag stored in system_settings)
  • If any check fails, a banner appears on the Ask Questions page: "Setup incomplete — fix issues in Operations → Setup Health Check"
  • Ingestion still works with failures, but a warning is shown inline
  • Can be re-run any time from the Operations tab
