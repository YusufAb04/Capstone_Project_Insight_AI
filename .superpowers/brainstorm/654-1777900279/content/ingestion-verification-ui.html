How it works under the hood

  • After ingestion, for each file: query ChromaDB for chunk count by file_path metadata
  • Compare against chunk_count stored in SQLite files table
  • If ChromaDB count = 0 and SQLite shows chroma_synced = 1 → flag as broken, reset chroma_synced = 0
  • "Re-ingest this file" button re-runs chunking + embedding for just that file
  • Also available as "Verify & repair index" button in Operations → AI / RAG Settings
